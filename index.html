    Conectar ao GitHub

    Para salvar o sensor no seu repositório, e todos verem, cole o token de acesso. Isso é pedido só na primeira vez neste navegador.

    Como criar o token
    1. No GitHub, clique na sua foto, depois em Settings → Developer settings → Personal access tokens → Fine-grained tokens.
    2. Clique em Generate new token, dê um nome (por exemplo, “Bancada SpO2”) e escolha uma validade.
    3. Em Repository access, escolha Only select repositories e marque só o repositório do site.
    4. Em Repository permissions, ajuste Contents para Read and write.
    5. Clique em Generate token, copie o código e cole aqui. O GitHub só mostra o token uma vez.

    Quem tiver o token consegue alterar os arquivos desse repositório. Cada pessoa deve criar o seu e não compartilhá-lo.
    Fichas cadastradas pelo formulário ficam no arquivo dados.json do repositório (se o GitHub estiver configurado) ou só neste navegador.
