    Cadastrar ou editar sensor

    1) Preencha os dados · 2) escolha o layout do conector · 3) clique em cada pino e diga o que ele é · 4) salve.

    PinoFunçãoFio

    Publicar ou guardar as fichas

    As fichas salvas ficam só neste navegador. Para colocá-las no site publicado, gere o trecho e cole no index.html. Para levar a outro computador, use o backup.

    Criar layout livre

    Escolha a forma e clique no desenho para posicionar os pinos, na ordem da numeração. Depois copie o JSON, cole no bloco “layouts” com um nome e use esse nome na ficha.

    JSON do layout

    Para adicionar um conector, edite os blocos JSON de layouts e dados e salve o arquivo.
